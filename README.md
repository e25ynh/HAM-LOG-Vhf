# HLVhf = HAM LOG VHF — V1.1.1

โปรแกรมบันทึก Log QSO โหมดเสียงย่าน **VHF / UHF (2m · 70cm)** สำหรับนักวิทยุสมัครเล่นขั้นต้น (VHF / UHF) แยกรุ่นมาจาก HLHf = HAM LOG HF (ขั้นกลาง-สูง) ให้เหลือเฉพาะงานโหมดเสียง ใช้ง่ายในหน้าเดียว

ทำงานบนเบราว์เซอร์ Chrome / Edge และติดตั้งเป็นแอปบน Windows และ Mac ได้ ไม่ต้องลงโปรแกรมอื่นเพิ่ม ข้อมูลทั้งหมดเก็บในเครื่องของผู้ใช้เอง ไม่ได้อยู่บน GitHub หรือเซิร์ฟเวอร์ใด ๆ

**เปิดใช้งาน:** https://e25ynh.github.io/HAM-LOG-Vhf/

## มีอะไรใหม่ใน V1.1.1 (2026-10-31)
- ปรับโค้ดให้ตรงกับ HLHf รุ่นล่าสุด และแก้การอ่านข้อมูลจาก NOAA SWPC ที่เปลี่ยนรูปแบบ (ค่า K / A)
- ไม่มีการเปลี่ยนหน้าตาหรือการใช้งาน ข้อมูล Log เดิมใช้ต่อได้ทันที

## มีอะไรใหม่ใน V1.1
- **รีพีตเตอร์ไทย:** เลือกจากรายการในแผงพิมพ์ความถี่ ตั้งความถี่ DUP ออฟเซ็ต โทน และโหมดครบในคลิกเดียว · เพิ่ม / ลบได้ที่ ตั้งค่า › รีพีตเตอร์
- **D-STAR:** ช่อง UR / RPT1 / RPT2 ใต้ฟอร์ม เลือกรีพีตเตอร์ D-STAR แล้วเติมให้เอง · บันทึกลง Log และ ADIF
- **ส่งค่าออฟเซ็ต DUP ไปวิทยุ** ผ่าน CI-V พร้อมความถี่ โหมด และโทน
- **MODE CW** ในหน้า VOICE · การ์ด CW บน Dashboard
- **Dashboard › QSO ล่าสุด:** ปุ่มครบที่เดียว · **ส่งออก ADIF ใหม่** (เฉพาะ QSO ที่ยังไม่เคยส่งออก) · **อัปเดตชื่อ / QTH / Grid จาก QRZ** ย้อนหลัง และแก้ Grid ที่ไม่ตรง
- **QR Code** ลิงก์แอปใน ตั้งค่า › เกี่ยวกับ · คัดลอกลิงก์ / บันทึกภาพ QR
- หน้า VOICE: MODE ชิดขวา · ตาราง QSO ไม่มีแถวปุ่ม (ใช้ที่ Dashboard) · หน้าตั้งค่าจัดกลุ่มใหม่

## ทำอะไรได้บ้าง

### หน้า Dashboard
- สรุปจากสมุด Log: QSO ทั้งหมด วันนี้ (UTC) 7 วันล่าสุด จำนวนจังหวัด และสถานีที่ไม่ซ้ำ
- การ์ดแยกตามโหมด: FM · SSB / LSB / USB · D-STAR / Digital Voice · VoIP · CW
- กราฟ **QSO 14 วันล่าสุด (UTC)**
- กราฟ **แยกตามจังหวัดที่ QSO** (แท่งแนวตั้ง) อ่านจังหวัดจากช่อง QTH ก่อน ถ้าไม่มีจะใช้ข้อมูลจาก QRZ รองรับชื่อไทย ชื่ออังกฤษ และชื่อเรียกอื่น เช่น Pattaya → ชลบุรี, Korat → นครราชสีมา, Hat Yai → สงขลา
- ตาราง **QSO ล่าสุด**: แก้ไขในช่อง เลือก ลบ ส่งออก ADIF / CSV · ส่งออก ADIF ใหม่ · อัปเดตชื่อ / QTH / Grid จาก QRZ

### หน้า VOICE (FM / SSB / LSB / USB / CW / Digital Voice / D-STAR / VoIP)
- **หน้าจอวิทยุจำลอง:**
  - โหมด ย่าน ความถี่ DUP / TONE และกำลังส่ง (PWR)
  - S-Meter และมาตรวัด ALC / SWR / TEMP / VOLT / AMP
  - Scope ของวิทยุ และ Audio Scope
- **แผงพิมพ์ความถี่:** คลิกตัวเลขความถี่บนหน้าจอวิทยุ
  - พิมพ์ได้หลายรูปแบบ: `145.625` · `145.337.500` · `145 337 500` · `145625` (kHz) · `145337500` (Hz)
  - ตั้ง MODE, DUP (SIMP / DUP− / DUP+ พร้อมออฟเซ็ต) และ TONE / TSQL (เลือกโทน 67.0–254.1 Hz) ได้ในแผงเดียว
  - ตั้ง DUP และออฟเซ็ตให้อัตโนมัติตามช่วงรีพีตเตอร์ไทย และแสดงความถี่ส่ง (TX)
  - ปุ่มความถี่ล่าสุด กดครั้งเดียวตั้งครบทุกค่า
  - ปุ่มลัด: Enter = ตั้ง · Esc = ยกเลิก · ↑ ↓ = ขยับทีละ 12.5 kHz (Shift = 25 kHz)
  - เลือก **รีพีตเตอร์** จากรายการ ตั้งครบในคลิกเดียว
  - ต่อวิทยุอยู่จะสั่งวิทยุเปลี่ยนตามผ่าน CI-V (ความถี่ · โหมด · DUP + ออฟเซ็ต · TONE / TSQL)
- **D-STAR:** ช่อง UR / RPT1 / RPT2 บันทึกลง Log และ ADIF
- **อ่านค่าจากวิทยุ:** ต่อวิทยุผ่าน USB แล้วอ่านความถี่ โหมด DUP / TONE และมาตรวัดจริงจากเครื่องตลอดเวลา
- **เสียงเข้า:** เลือกอุปกรณ์เสียงไว้ที่ตั้งค่า แล้วหน้า VOICE จะเปิดฟังเสียงให้เอง ปิดได้
- บันทึก QSO พร้อมดึงชื่อ / QTH / Grid ของคู่สถานีจาก QRZ.com และ HamQTH.com
- ตาราง Log แบบแบ่งหน้า และแท็บแผนที่ตำแหน่งคู่สถานี

### การเชื่อมต่อวิทยุ
- Icom (CI-V) เช่น IC-9700 และ IC-705 รวมถึง Xiegu
- Yaesu และ Kenwood / Elecraft ผ่านคำสั่ง CAT
- เพิ่มวิทยุได้หลายเครื่อง แยกการตั้งค่าต่อเครื่อง

### บันทึกและส่งต่อข้อมูล
- นำเข้า / ส่งออก **ADIF** (ใช้ต่อกับ Log4OM และโปรแกรม Log อื่นได้)
- ส่งออก CSV
- สำรองและกู้คืนการตั้งค่า + Log เป็นไฟล์ .json (ใช้ข้ามกับ HLHf ได้)

### อื่น ๆ
- ช่องล็อกอิน QRZ / HamQTH พิมพ์ตัวเล็ก-ใหญ่ได้อิสระ (HamQTH ใช้ Callsign หรือ Email) และมีปุ่มรูปตาดูรหัสผ่าน
- QR Code ลิงก์แอปสำหรับแชร์ให้เพื่อน
- ติดตั้งเป็นแอปได้ (PWA) อัปเดตอัตโนมัติ บันทึก Log แบบออฟไลน์ได้
- ธีมสว่าง / มืดเปลี่ยนเองตามเวลา
- คู่มือในตัว 2 ภาษา (ไทย / English)
- ไม่มีรุ่นย่อย ทุกฟังก์ชันเปิดใช้ได้ทั้งหมด

## ย่านความถี่

| ย่าน | ช่วง (MHz) | ใช้บ่อย |
|---|---|---|
| 2m | 144.000–147.000 | FM ซิมเพล็กซ์ / รีพีตเตอร์ · SSB ช่วงต้นย่าน |
| 70cm | 430.000–440.000* | FM · D-STAR · ดาวเทียมบางช่วง |

อ้างอิง RAST และ IARU R3 · * = ยังไม่ยืนยัน · สิทธิ์ใช้งานขึ้นกับชั้นใบอนุญาต ตรวจกับประกาศ กสทช. ล่าสุดก่อนใช้งานจริง

## สิ่งที่ต้องมี
- Chrome หรือ Edge รุ่นใหม่ ต้องรองรับ Web Serial เพื่อต่อวิทยุ และเปิดผ่านลิงก์ https
- สาย USB ของวิทยุ ถ้าต้องการให้โปรแกรมอ่านหรือสั่งความถี่
- บัญชี QRZ.com และ/หรือ HamQTH.com ของตัวเอง ถ้าต้องการดึงข้อมูลคู่สถานี

## ข้อจำกัดที่ควรรู้
- ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง ถ้าล้างข้อมูลเว็บไซต์หรือย้ายเครื่อง ต้องสำรองแล้วนำเข้าใหม่
- คำสั่ง CI-V ของแผงพิมพ์ความถี่ (รวมออฟเซ็ตและโทน) ทดสอบกับวิทยุจำลองแล้ว ยังทดสอบกับเครื่องจริงได้จำกัด
- รายการรีพีตเตอร์ตั้งต้นมาจาก RepeaterBook ซึ่งยังไม่ได้ยืนยัน ตรวจกับสมาคม / ชมรมก่อนใช้งานจริง
- อัปโหลด Log ขึ้น QRZ / LoTW โดยตรงยังไม่ได้ ใช้วิธีส่งออก ADIF
- D-STAR: ช่อง UR / RPT1 / RPT2 ยังไม่ได้ส่งไปตั้งในวิทยุ และยังไม่มีรายชื่อรีเฟล็กเตอร์
